Este repositório reúne os materiais do projeto de extensão da disciplina de Tópicos Especiais 2, do 8º semestre de Sistemas de Informação da UDESC. No vídeo, demonstramos como desenhar formas geométricas no turtlesim usando ROS, controle proporcional e PID.
